# Бот транспортного логиста @EVAPress_bot

Telegram-бот на Python 3.11+ (aiogram 3, SQLite) для работы с маршрутными листами.

## Доступ и роли

Бот закрытый: войти можно только по одноразовой ссылке-приглашению (кнопка «🎟 Пригласить», ссылка действует 7 дней). Человек открывает ссылку и вводит ФИО. Без приглашения бот отвечает «Бот закрытый».

| Роль | Права |
|---|---|
| 👑 Администратор | Всё: загрузка Excel, назначение маршрутов, сообщения водителям, инструкции, закрытие рейса, ZIP, приглашения, управление пользователями |
| 👁 Заказчик | Только просмотр: кнопки «Статистика» и «Отчёт»; в отчёте по маршруту — фото и примечания (без добавления, изменения и удаления) |
| 🚚 Водитель | Маршрут, закрытие точек с фото, «Проблема на адресе», инструкции |

Telegram ID из переменной `ADMIN_IDS` всегда считаются администраторами. Через них приглашаются все остальные.

## Возможности

**Водитель**
- Регистрация по ссылке-приглашению (вводит ФИО).
- «🚚 Начать маршрут» — загружаются все точки назначенного маршрута. Нажатие на точку показывает подробности: адрес, сеть, № точки, № 1С, количество, комментарий.
- «📍 Открыть точку» → бот по шагам просит 3 фото:
  1. выкладка продукции;
  2. накладная с печатью и подписью грузополучателя;
  3. доверенность на возврат **или** кнопка «🚫 Доверенность отсутствует».
- На каждом шаге подсказка: «Следите за тем, чтобы фото были чёткие и читабельные».
- После трёх обязательных фото можно отправить любое количество дополнительных фото (а также видео или файлов) — для нестандартных ситуаций. Затем «✅ Закрыть точку». Есть «🔁 Переснять фото». Точку нельзя закрыть без обязательных фото.
- «⚠️ Проблема на адресе» — показывает памятку с порядком действий и контактами, затем водитель выбирает адрес, пишет комментарий и прикрепляет фото (несколько сообщений, количество фото не ограничено), потом нажимает «📨 Отправить логисту». Логист сразу получает текст и все фото, с кнопкой «Ответить водителю».
- «📖 Инструкции» — список инструкций.
- ❗ Важные примечания логиста видны в маршруте (к маршруту в целом — вверху списка, у точек с примечаниями — значок ❗) и в карточке точки, а также сразу при «Открыть точку».
- «📝 Заметка к адресу» — водитель оставляет заметку для других водителей (въезд, часы приёмки, контакты). Она уходит логисту на утверждение и после него видна всем водителям на этом адресе во всех будущих маршрутах.
- Стартовый экран водителя — постер `assets/poster_start.jpg` (при входе по приглашению и по `/start`).
- «🏁 Закрыть рейс» — водитель отправляет запрос на закрытие своего маршрута (кнопка внизу списка точек; если остались незакрытые точки, бот их перечислит). Администратор получает уведомление и нажимает «✅ Подтвердить закрытие» или «❌ Отклонить» (с причиной для водителя или без). Пока запрос ждёт решения, водитель может продолжать закрывать точки.
- После подтверждения закрытия — или закрытия рейса на дату администратором — водитель получает постер «Благодарим за отличную работу!» (`assets/poster_thanks.jpg`). Администратор может снова открыть маршрут кнопкой «↩️ Открыть маршрут снова».

**Администратор (логист)**
- 📥 Загрузка Excel: просто отправьте файл в чат. Дата берётся из имени файла (`04.11.2026_….xlsx`) или из подписи к файлу. Если даты нет ни там, ни там, бот её спросит. Каждый лист — номер маршрута, лист «итого» пропускается. Повторная загрузка файла на ту же дату обновляет адреса и сохраняет закрытые точки, фото и назначения.
- 🧭 Назначение маршрутов: дата → маршрут → водитель (водитель получает уведомление).
- 📊 Статистика: `/stats`, `/stats 04.11.2026`, `/stats 1 6 14`, `/stats 04.11.2026 1 6`.
- 📑 Отчёт по дате и маршруту: `/report 04.11.2026 14` или через кнопку. В отчёте: закрыто/не закрыто, ФИО водителей, список незакрытых адресов, проблемы, кнопка «🖼 Фото по маршруту».
- 📤 Выгрузка Excel в любой момент: `/export` или `/export 04.11.2026`.
- 📖 Инструкции: добавить / изменить / удалить (текст, можно с фото, видео или документом).
- ✉️ Сообщение водителям во время рейса: всем на маршрутах, всем водителям или конкретному водителю (текст, фото, голосовое и т.д.).
- ➕ Добавить инструкцию — отдельная кнопка в меню.
- 🔒 Закрыть рейс + дата: все маршруты на дату закрываются, водители больше не могут закрывать точки, бот присылает отчёт и итоговый Excel. Рейс можно открыть снова.
- 🗜 Сохранить .ZIP: архив `04-11-2026.zip` — итоговый Excel и папки маршрутов (`1/`, `2/`, …) со всеми фото водителей (`01_адрес_1_выкладка.jpg`, `…_2_накладная.jpg`, `…_3_доверенность.jpg`, дополнительные `…_4_доп_1.jpg`, фото к проблемам `…_проблема_1.jpg`). Telegram не даёт боту отправлять файлы больше 50 МБ, поэтому большой архив приходит частями: `04-11-2026_часть-1-из-3.zip` и т.д.
- 🎟 Пригласить и 👥 Пользователи: приглашения, смена роли, удаление.
- ⚙️ Текст «Проблема»: редактирование памятки и контактов.
- 📝 Примечания: дата → маршрут → «➕ Примечание к маршруту» или «➕ К адресу», затем «только на эту дату» или «постоянно». Водитель на маршруте сразу получает уведомление. Там же — список примечаний и заметок с кнопкой удаления, и заметки водителей на утверждении (✅ Утвердить / ❌ Отклонить). Кнопка «📝 Примечания к маршруту» есть и в отчёте. Постоянные примечания и заметки к адресу привязаны к № 1С (если его нет — к адресу) и действуют для всех будущих дат.
- Уведомления: регистрация водителя, начало маршрута, проблема на адресе, маршрут выполнен.

## Как формируется Excel

Бот хранит исходный загруженный файл и при выгрузке меняет **только** ячейки:
- **«кол-во ТК»**: `1`, если точка закрыта, `0`, если не закрыта;
- **«комментарии»**: сюда дописывается текст «Проблемы на адресе», только у точек, по которым водитель сообщал о проблеме. Существующий комментарий сохраняется. Отключается настройкой `WRITE_PROBLEMS_TO_COMMENTS=0`.

Листы, порядок и названия столбцов, стили, ширины, формулы `SUM`, лист «итого» остаются без изменений: правка идёт напрямую в XML файла, без пересохранения через библиотеку. Столбцы бот находит по названиям в шапке («адрес», «кол-во ТК» и т.д.). Точки — это строки с заполненным адресом до строки «итого» / формул.

## Установка

1. Получите токен @EVAPress_bot у @BotFather (`/token`).
2. Узнайте Telegram ID администраторов: запустите бота и отправьте `/myid` (или спросите у @userinfobot).
3. Установите зависимости и настройте:

```bash
cd evapress_bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env    # впишите BOT_TOKEN и ADMIN_IDS
venv/bin/python bot.py
```

### Автозапуск на сервере (systemd)

`/etc/systemd/system/evapress-bot.service`:

```ini
[Unit]
Description=EVAPress logistics bot
After=network-online.target

[Service]
WorkingDirectory=/opt/evapress_bot
ExecStart=/opt/evapress_bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now evapress-bot
```

## Сохранность данных

- Код (файлы из GitHub) и данные (папка `DATA_DIR`: база `bot.db` и Excel-файлы) лежат отдельно. Обновление кода данные не трогает: при старте бот только добавляет новые таблицы и колонки, ничего не удаляя.
- На хостинге с пересборкой контейнера (BotHost) `DATA_DIR` обязательно должен указывать на постоянное хранилище.
- Страховка на случай, если хостинг всё же потеряет файлы: два раза в сутки, в `BACKUP_TIMES` (по умолчанию 09:00 и 21:00), бот присылает в канал резервных копий (или, если канал не подключён, администраторам из `ADMIN_IDS`) файл `evapress_backup_ГГГГ-ММ-ДД_ЧЧММ.zip` (база + Excel; фото хранятся в Telegram, в копии — ссылки на них). Копию по запросу — кнопка «💾 Резервная копия» или `/backup`.
- Восстановление: отправить файл копии боту → бот покажет, что в копии и что сейчас, → «✅ Восстановить». Текущая база перед заменой сохраняется на сервере как `before_restore_….db`.
- **Автокопия и автовосстановление.** Через 5 минут после любых изменений (и при остановке бота перед пересборкой) бот обновляет закреплённое сообщение «💾 Автокопия данных бота» в личном чате с первым администратором из `ADMIN_IDS` (или в канале `BACKUP_CHAT_ID`). Если при запуске база пустая — бот сам скачивает закреплённую автокопию, восстанавливает данные и сообщает об этом администраторам. Это сообщение нельзя удалять и откреплять.
- Если автокопии нет, а база пустая, бот предупредит администраторов и предложит прислать последнюю копию вручную.

## Данные

Всё хранится в папке `data/`: `bot.db` (SQLite), `workbooks/` (загруженные файлы), `exports/` (выгрузки). Фото хранятся в Telegram по `file_id`, их можно посмотреть через отчёт → «🖼 Фото по маршруту». Для резервной копии достаточно копировать папку `data/`.
